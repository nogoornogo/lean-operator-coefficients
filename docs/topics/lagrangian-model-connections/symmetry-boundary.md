# Symmetry Certificate Boundary

The [successor](../euler-naturality/README.md) closes the constant linear
field/direction case with semantic descent and a graded chain rule. The
remaining text records the predecessor endpoint and its component route.

The implemented theorem takes multiplicativity of the source action,
constant-matrix covariance of ordinary derivatives, and covariance of the
total Euler-family span. It derives stability of every two-sided differential
EOM descendant and the linear divergence range. This is a smaller reusable
certificate than a proof about the whole generated relation module.

The syntax-naturality route did not at this endpoint yield a generic constructor
from semantic density invariance alone. `Expr.first_variation` computes Euler
terms and currents; `variation_agrees` compares them with a specified actual
evolutionary derivation. Neither declaration proves transformation naturality
of the Euler operation under arbitrary linear field/direction actions.

In particular, density symmetry is an equality after evaluation. Field
anticommutation, component contractions and commuting derivative words can
make this equality hold without equality of syntax trees. A proof based only
on literal syntax equality would miss the checked spinor examples. Completing
the semantic route requires the corresponding graded variational chain rule
and compatibility with the chosen Euler/IBP normal form; these were not added
as new premises or claimed proved here.

The bounded route succeeds: compute the full Yukawa Euler family, identify it
with independently written covariant maps, and apply `ofEulerSpan`. The total
density's Lorentz invariance is also proved independently. Registered callers
supply couplings, while arbitrary new interactions still require an updated
certificate. This boundary does not restrict the underlying all-order theorem,
which accepts any checked stable input.
