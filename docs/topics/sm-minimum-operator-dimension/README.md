## Endpoint And Scope

Determine exact minimum engineering dimensions in the fixed derivative-free,
three-generation, ten-signed-species SM dictionary with independent Lorentz
actions, one residual-neutral Higgs/dual and scalar cyclic q/l actions.
The [frozen initial plan](plan.md) fixes four input/sector pairs, two proof
routes and the stopping conditions. Each minimum needs actual original-space
attainment and a lower bound for every selected allowed content and every
Higgs bidegree. Minimum absolute lepton charge alone is insufficient.

The initial endpoint is four bounded examples and a reusable minimum
specification, not a formula for all k,q,l or optimization of all 572 rows.
If existing interfaces cannot settle a case within the frozen routes, retain
proved bounds and report that case unresolved. Do not turn a failed witness
search into a prohibition claim.
