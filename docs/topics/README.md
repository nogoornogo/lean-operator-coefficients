# Topic Index

The [topic outcome guide](_history/README.md) gives a reading-order record of
completed integrations and settled stops. It uses names, folder links and short
outcomes, without dates or commit IDs. This subject index links every immediate
topic directory containing a README, including active and retained topics.
`_history` is navigation infrastructure, not a topic.

Each topic owns its plan, status, scoped result and verification in one stable
directory. This subject index contains links, not duplicated status or obligation
lists. Completion does not make a topic obsolete or authorize further work.
See [workflow](../architecture/WORKFLOW.md) and [template](TEMPLATE.md).

Primary subjects follow Math / Physics / GUT, with infrastructure separate.
Cross-layer topics appear once, according to their main endpoint; their own
records link related layers. This is navigation, not a claim about source imports
or a prescribed research order. Completed generalizations and bounded sector
checks retain their own acceptance gates and scope; completion is not a claim
of coverage of all EFT operators.
