## Independent all-107 certificate route

[The generator](../../../tools/structural-support/neutral-certificates.py) uses
the reference signs only to propose statements; there is no CSV/Weyl/rank
premise in any accepted theorem.

For all 66 zeros, the existing `SMConstantWeakCapacity.bound` is too small for
the requested weak label. `constantWeakCutoff` transports the existing actual
local-source vanishing theorem to exactly `SMJointContentSupport.Supports`,
with neutral hypercharge and the bound proved separately for each closed key.

For larger positive Q contents, the candidates use occupations (0,6,6) at
n=12, (6,6,6) at n=18 and (6,6,12) at n=24, with their conjugates. A typed
indexed constructor places these occupations in the actual ten-species tree.
The candidate first branch must exist, and its **joint** color/weak/two-spin
validity is kernel-checked. No color/spin witnesses from different branches
are mixed. Smaller positive contents use the current compact decision.

The final generated file contains 107 closed sign theorems and the larger
mixed OriginalSpace prohibition via the already-proved odd-chirality theorem.
It passed exit 0 in **26.0 seconds**, sampled group peak **5629024 KiB** (about
5.37 GiB), with zero warnings/errors and **334 strict transitive checks**.
The source digest is recorded in the summary; rerunning the generator reproduces
that exact candidate file. The comparison proves signs only, not the CSV's exact
multiplicities/ranks or all-content support beyond the original structural iff.

Prototype development corrected a dependent conditional transport/type mismatch
and a noncomputable annotation. Searching every branch even after fixing an
occupation still hit unchanged kernel recursion limits on Q18. Specifying an
actual branch witness removed that search. Both failed prototype files were
rejected, including by the audit's recovery-axiom check; neither is counted as
passing. The refinement changed candidate proof structure, not the resource
ceiling, theorem meaning, field input or axiom gate.

## What remains a decision rather than an unrun check

The present general decision path has real compiled-execution and measured
resource limitations. Nevertheless, the existing theorem interfaces support
fast checked certificates for this fixed domain using existing symbolic filters
and explicit witnesses. This supports separating mathematical correctness,
automatic search strategy, witness checking and compiled executability when
judging a rewrite. It does not choose that rewrite, prove worst-case complexity,
or deliver an all-content runtime API. No further design implementation was
started after finishing these checks.
