The first representation class is a single complex eigenline with character
chi, and a pair of eigenlines with inverse characters. The source X is an
arbitrary actual complex group representation, including an already constructed
exterior fermion carrier. Degrees are unrestricted natural numbers. This class
does not identify the SM weak doublet with a line or restrict the full SM

## Endpoint

1. Construct an actual linear equivalence from every symmetric power of the
   complex line to the line, including degree zero, with its character action.
2. Transport invariant coefficients, in both directions, to linear source
   functionals with the corresponding character covariance condition.
3. Prove that equal total characters give equivalent coefficient spaces.
   In the inverse-character pair, cancel a common number of Higgs/dual insertions.
4. When chi has a supplied positive period k, prove reduction to degrees less
   than k, and an iff between all-degree vanishing and a finite set of tests.

The finite test may be reduced further to the k one-axis degrees (j,0).
The existing LLHH result also supplies an actual SM control separating
residual neutrality from the eigenline hypothesis; no new model is introduced.

No seed-existence, coefficient nonzero, finite-generation or spanning premise
is permitted. Character period is explicit and mathematical; it is not a
physical assumption about the SM gauge action. The reduction must preserve
both zero and nonzero coefficient spaces, rather than only propagate seeds.
