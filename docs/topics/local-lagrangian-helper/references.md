# Sources And Roles

- Existing mixed jets, Grassmann contraction/parity, scalar first variation,
  differential EOM ideals and derivative input adapters: proved implementation
  inputs. See the [preceding interface topic](../derivative-interface-adapters/README.md)
  and [first-variation topic](../formal-first-variation/README.md).
- G. Sardanashvily, *Grassmann-graded Lagrangian theory of even and odd variables*,
  [arXiv:1206.2508v1](https://arxiv.org/pdf/1206.2508v1), Theorem 16 and formula (37):
  graded first-variation and Euler/boundary decomposition background. Selected
  inspection only; no graded manifold, cohomology or variational-bicomplex
  theorem is imported as a premise. This implementation proves an algebraic
  finite-expression identity in the existing jet algebra.
- Pinned mathlib exterior algebras, tensor products, polynomial derivations,
  finite sums and submodule quotients: reusable mathematical APIs.

Final result links and these limited source roles are reconciled into the shared
[literature list](../../proof/RELATED_LITERATURE.md). No external theorem is
introduced as a completeness or first-variation premise.
