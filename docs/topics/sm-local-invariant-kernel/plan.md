# Frozen Finite Matrix Connection Plan

## Input and endpoint

Retain the existing ten signed species, three flavor copies, one neutral
Higgs/dual, actual SU(3) color, SU(2) weak, U(1) hypercharge and paired
SL(2,C) left/entrywise-conjugate-right Weyl action. Residual q/l charge has
already been separated. All exterior/symmetric statistics remain imposed.

For each content and constituent, specify a finite coordinate system for
the actual carrier and actual group elements labelling finite constraint
rows. For a coordinate functional c and basis vector v_j, a row tests

    f_c(rho(g_i) v_j) - f_c(v_j) = 0.

Thus the matrix entry is the j-coordinate of rho(g_i) minus the identity,
with the transpose appropriate to functional coordinates. Prove the
orientation by evaluation, both inverse maps and the kernel iff. A
rank/dimension predicate may be consumed only after this equality is proved.

## Ordered construction

1. Generic exact matrix consumer: finite actual group tests on a finite
   carrier basis; prove invariant coefficients are exactly its kernel when
   those tests are exhaustive. Keep exhaustiveness explicit in this generic
   theorem; do not claim it for the SM consumer before discharging it.
2. Prove invariance iff invariance on a supplied algebraic generating set.
   Discharge generation for the actual SL(2,C) Weyl group using pinned
   transvections, preserving the joint left/right action. This is group
   generation, not a Lie/group integration premise.
3. Polynomial sampling: for a one-parameter action with a proved coordinate
   polynomial degree bound D, prove D+1 distinct samples are exhaustive.
   For paired z/conj(z) Weyl actions use real/imaginary parameters with an
   exact two-variable grid; never treat z and conj(z) as independent actual
   group elements. Statistical quotient/image descent must retain the
   coordinate polynomial identity and bound.
4. For color/weak use actual special-unitary elements and a certified
   generating-family route. Inspect the pinned unitary/classical-group
   assets once for this prerequisite. Do not substitute SL shears unless
   the invariant-space correspondence has separately been proved.
5. Compose all discharges into the actual original-carrier finite matrix
   equivalence, register sources/audits, verify and commit the scoped result.

## Stop conditions

The allowed work includes exact matrix coordinates, generator-invariance
transport, bounded polynomial interpolation, and statistical descent within
those interfaces. Stop at the first actual special-unitary generating-family
or polynomial source/descent certificate that requires a new foundational
milestone rather than these bounded constructions. Record the precise
remaining statement and the established inputs, not an impossibility claim.

A generic conditional kernel equivalence, existence of finitely many tests
by classical choice, a Lie kernel, or a finite sampled calculation does not
complete the actual fixed-input endpoint. Do not conceal this distinction.
No new dependency, heartbeat setting, custom axiom, audit exception or
non-symbolic computational environment is allowed. No general compact-group
classification or invariant-theory finite-generation library is started.

## Acceptance

Focused builds and strict persistent transitive axiom audits, then one
serialized full lake build, layout/link/diff checks, statement/assumption
review and a verified commit. If a stop condition is reached, keep the
fixed-input endpoint open and preserve only coherent proved interfaces.
No parent/master integration or remote push is part of this request.
