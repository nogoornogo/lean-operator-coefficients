## Endpoint And Scope

Compare three specified literature models, in order, with the admission
conditions of the [model-independent common-copy theorem](../su5-matter-mass-protection/model-independent-result.md).
Determine which conditions can be instantiated, which fail, and which remain
unproved. Do not assume that a claimed stable-proton model must fail the theorem:
a nonzero coefficient space need not have a generated interaction.

The three bounded comparisons have reached their recorded algebraic/feasibility
endpoints; focused/full builds and documentation checks passed. See the [staged plan](plan.md),
[source register](sources.md), and [verification record](verification.md).

## Deliverables And Acceptance

Each model receives a field/action/VEV dictionary, an exact mass and light-field
specification, an admission-condition comparison, and a bounded algebraic result
or explicit feasibility boundary. Reader-facing findings belong to
[model studies](../../model-studies/README.md); the
[coverage ledger](../../verification/proton-protection-model-coverage.md) indexes
only their source-to-result status.

## Work And Open Obligations

The [phase contracts](phase-contracts.md) fix the evaluated dictionaries. See
[the combined evaluation](evaluation-result.md) for closed conditions and
remaining boundaries. No whole-model proton-stability theorem is claimed.

## Result And Verification

B/L has a necessary common-source action obstruction and conditional physical
qque vanishing for arbitrary finite uniform flavors. Gauge-only split SU(5)
and minimal PS remain feasible on supplied light dictionaries. Exact light
parity is a separate conditional SU(5) obstruction, not invariant on the
original mixing mass. See the [evaluation](evaluation-result.md) and
[verification](verification.md). UV adapters and nonlinear matching remain
outside this completed bounded pass. The topic is integrated into master; see the merged-state verification record.
