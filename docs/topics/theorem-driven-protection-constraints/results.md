# First-Phase Results

## Endpoint

The two planned routes yield conditional necessary constraints and symbolic
parameter pullbacks. A finite enumeration interface is proved sound when
its input type is finite and its predicates are decidable. No exhaustive
model input space, new protecting model, or automatic physical admission
procedure has been constructed.

The [constraint register](constraints.md) distinguishes theorem consequences,
application hypotheses, SM predicates and remaining physical bridges.

## Scalar/cyclic route

[ProtectionConstraintPullback](../../../Math/RepresentationTheory/ProtectionConstraintPullback.lean)
proves `cyclic_necessary`, `cyclic_retain`, and `neutral_excludes` using the
existing scalar-action iff. Parameters, charge order and genuine represented
carrier are general; no finite-dimensionality is added. Nontriviality is
required on the actual carrier. `neutral_line_not_forbidden` is a genuine
cyclic character-line regression. `zero_domain_control` proves why the
nontriviality premise cannot be dropped. Neither line is a physical SM sector.

## Physical surplus route

[SpeciesSurplusNecessity](../../../Physics/FieldTheory/Mass/SpeciesSurplusNecessity.lean)
uses the existing original-mass Realization and its derived light exterior
coefficient. `ForbiddenExterior` refers to the actual participating physical
Q/U/E exterior coefficient space. `no_joint_surplus` shows prohibition rules
out simultaneous positive Hom surplus for a common irreducible.
`bottleneck` gives the explicit disjunction of three non-strict inequalities.
`count_bottleneck` pulls these back to six symbolic natural parameters when
certified as the actual Hom dimensions. No target semisimplicity is added.
The irreducible and source semisimplicity premises remain explicit.

A total-B1 application must establish that all-B1 prohibition restricts to
this physical participating domain. That is not a new all-B1 classification
here. The existing mass-independent sector-presentation constructor can
supply the Realization for every mass under its pairing hypotheses; this
phase does not supply it for arbitrary unknown field data.

## Predicate preimages and finite filtering

`retain` is S(x) AND (A(x) -> N(x)). `preserve` proves every protected input
satisfying S survives; `exclude` rejects protection only with proved A and
failure of N. `keep_outside` formally retains inputs outside applicability
when S holds. Missing evidence must not be treated as a proof of not-A.

`finiteCandidates` filters a finite parameter type using the same predicate;
`mem_finiteCandidates` proves preservation. Decidability is a separate input,
not a consequence of having finitely many parameter labels. A computational
three-way classifier for missing proof evidence is not claimed. Nor is a
finite table of models produced: no bounded physical family has been specified.

## What this changes and what it leaves open

Instead of stopping at "supply model inputs", the output can now be written
as charge inequalities or six Hom-count inequalities, conditional on named
application premises. This is a small, auditable use of existing theorems,
not a newly discovered physical no-go or a converse existence theorem.
SM predicates are explicit external constraints. UV representation/VEV/action
construction and unknown radical identifications remain model obligations.
The standard-chain and full-constituent routes are reference consequences,
not reopened adapter projects. No rates, derivatives/EOM/IBP, anomalies,
new libraries, general noncommuting classification or numerical environment
are introduced.

The frozen stopping condition is met after the verification in
[verification](verification.md). A next phase requires choosing a bounded
parameter family whose applicability/count dictionaries can actually be
certified, rather than assuming this package fills those dictionaries.
