## Objective and fixed direction

Fix existing theorem routes first. Extract what B1 prohibition would require
within each route's admitted scope. Define only input templates that express
those consequences, then pull the constraints back to template parameters.
Combine explicit SM conditions with them and retain the resulting necessary
conditions or contradictions. Concrete model search comes afterwards.

The [previous route inventory](../su6-light-placement-search/input-axis-theorem-map.md)
is overlapping proof coverage, not a partition. It must not be used as a
checklist of missing generic proofs. A missing bridge is recorded as a premise
or bounded feasibility outcome, not silently inferred from finite data.

## Frozen first endpoint

Use at most two implementation routes in this first phase:

1. Scalar/cyclic prohibition on an actual nontrivial admitted carrier: pull
   back the existing charge-detection necessity to a symbolic parameter family.
2. Species copy-surplus: turn its existing physical nonzero-qque implication
   into necessary no-surplus constraints for B1 prohibition, retaining actual
   sector presentations and semisimplicity.

Record the common-constituent criterion and standard-chain obstruction as
reference consequences. Do not rebuild their generic adapters. The standard
chain is a regression exclusion, not a new SU(6) model search.

residual actions admitting a neutral qque triplet on actual invariant light
subspaces. It combines the necessary residual test with the full-family SM

existing neutral-qque evidence for input filtering; passing it is not proof
of protection, and charge tables do not establish physical admission.
