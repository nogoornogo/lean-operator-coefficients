# Constraint Register

The first two rows are implemented in this topic. The last two are existing
reference routes. A theorem's prerequisites are not universal physical
necessary conditions. Every output below is scoped to its admitted domain.

| Route | Application prerequisites | Derived requirement if protection holds | Explicit SM/physical obligation | Strength |
| --- | --- | --- | --- | --- |
| Scalar/cyclic | Nontrivial actual residual carrier after local/statistics relations; genuine cyclic action with certified scalar charge q | q != 0; neutral admitted inputs cannot be forbidden | Actual selected coefficient correspondence and total-B1 to selected-factor implication | Iff for this invariant-functional domain; necessary only for total B1 |
| Species surplus | Actual invariant symmetric mass; species Realization; semisimple source copy representations; common finite irreducible r | For every such r: sourceQ <= targetQ OR sourceU <= targetU OR sourceE <= targetE, using Hom multiplicities | Actual sector presentations/mass squares; total-B1 prohibition must imply vanishing on these physical participating exterior fields | Necessary, not sufficient |
| Full qque constituent | Full admitted Q/U/E multiplicities; symmetric-square source semisimplicity | No shared constituent of Sym² Q and the specified U/E product | Actual full-field extraction and action compatibility | Exact qque criterion; not all-B1 sufficiency |
| Standard chain | Actual ambient commuting product action; standard chain; invariant mass; requested pure SM dual index | Profile equality Q=U=E; incompatible nonzero-qque pure charge targets are excluded | Embedding and target character dictionary; desired target is not assumed realized | Existing target exclusion, not arbitrary GUT no-go |

"SourceQ" means dim Hom_H(r,A_Q), not total dim A_Q. Total copy dimensions
cannot replace it for arbitrary non-scalar representations. An r-dependent
bottleneck may occur in a different species for each r. No single species
is proved to be the bottleneck for all irreducibles.

## Parameter interface

For x in a parameter type, use separate predicates:

- A(x): the route's applicability evidence;
- S(x): explicit supplied SM constraints;
- P(x): actual selected prohibition, or total prohibition with a proved selected-domain implication;
- N(x): the extracted numeric/representation constraint.

The certificate is A(x) -> P(x) -> N(x). Retention is
S(x) AND (A(x) -> N(x)), not simply S(x) AND N(x) for unknown applicability.
Within the admitted domain it reduces to S(x) AND N(x). S is not a verified
SM-consistency algorithm in this package. Passing retention proves neither
P nor existence of a UV model, an invariant vacuum, or an exact radical.

For the surplus route, `count_bottleneck` derives an explicit six-integer
condition from actual Hom-count equalities. `count_parameter_retain` consumes
the resulting family certificate; that argument is deliberately still visible.
The package does not manufacture every parameter's physical Realization.
