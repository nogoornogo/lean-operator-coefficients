The [frozen continuation](copy-count-plan.md) is complete. This is the direct
necessary-condition form of an existing arbitrary-copy result, not a new
physical no-go or an enlarged classification.

## Actual family and numeric output

[MatrixTenMass](../../../GUT/SU5/SelectionRules/MatrixTenMass.lean) already
constructs actual fields from p source tens, one bar-five and q dual-target
tens, with genuine scalar ten character chi and independent bar-five
character psi. Three unrestricted q-by-p complex matrices define the species
mass map and the symmetric Dirac mass. Their light maps, radical membership,
residual/gauge actions and physical exterior coefficient are proved.

[CopyCountProtectionConstraint](../../../GUT/SU5/SelectionRules/CopyCountProtectionConstraint.lean)
now states the necessary output directly: **p <= q**. No Hom-count equality,
rank certificate or preassigned zero mode is supplied to this consumer.
If q<p, existing kernel existence constructs all three participating species
for any matrix entries and yields the contradiction.

`ParticipatingForbidden` requires vanishing on every participating light
range certified by the existing `Kernels` structure. Total B1 prohibition
would need to imply this selected-range condition; the source does not assert
that this predicate equals total B1 prohibition. The output does not depend
on psi, because the selected qque domain uses only the ten-side species;
existing theorems establish light membership for every admitted psi.

`source_le_target` extracts p<=q; `surplus_excludes` rejects q<p;
`parameter_retain` permits arbitrary parameter-dependent counts and matrices.
The admissible family is fixed by construction, rather than supplied as six
numeric Hom-dimension equalities. The extra SM predicate remains explicit.

## Non-converse controls

`two_one_excluded` rules out every matrix choice with two source copies and
one target copy. `balanced_counts_not_sufficient` uses p=q=1 and three zero
matrices: explicit nonzero kernel vectors still give a physical nonzero
coefficient. Thus passing p<=q does not prove protection. No claim that this
balanced control reproduces the SM spectrum is made.

This does not establish an exact SM radical for arbitrary p,q or matrices.
The copy family already contains the required gauge species structurally;
additional light pairs, singlet counts, anomalous matter or phenomenological
viability are not decided by this inequality. An SM index predicate has not
been computed or certified in this continuation.

## Comparison with preceding work

The positive-surplus implication was already proved in MatrixTenMass.
The current contribution is its reverse consumer and sound parameter
retention, with the family instantiated so a new copy-count dictionary is
unnecessary. It does not remove the hypotheses of the scalar-copy carrier
or Dirac mass, nor demonstrate a new useful surviving UV input region.
Further generalization would need a separately frozen actual family and
its SM conditions; no such exploration is started here.
