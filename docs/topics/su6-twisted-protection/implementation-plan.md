# Authorized Covariant Model Interface

The user authorized planning and implementation of the missing interface.

## Frozen Endpoint

1. A Math-owned action covariant under a supplied homomorphism into group
   automorphisms. Prove local relation-span stability and invariant Hom descent
   without strict commutation. No automorphism classification is needed.
2. A GUT-owned SU(6) interface with actual finite-dimensional continuous-unitary
   fermion/scalar carriers, ordinary Abelian residual actions, supplied
   automorphism action, unbroken gauge embedding, fixed VEV and invariant
   symmetric mass. Derive preservation of the mass radical by the residual
   action; expose a typed dual-index target predicate on the actual radical.
3. Explicit coefficient-interface boundary: the Math descent applies to a
   supplied covariant coefficient carrier; no unproved extension to exterior
   sectors or generated interactions is bundled into the SU(6) model.
4. Named identity-automorphism recovery of strict commutation, independent
   noncommuting control, strict transitive audits, focused and full builds,
   layout and link checks, then a topic checkpoint commit.

Target representations and positive SM generation data are application inputs;
no arbitrary target representation is labelled SM automatically. A protecting
inhabitant, automorphism classification, realistic Yukawas, a dynamic vacuum,
full tensor/exterior covariance and quantum exactness are not this endpoint.
The model is a necessary-data interface, not a proton-stability certificate.

No toolchain/dependency change, new axiom, audit exception or master merge.
