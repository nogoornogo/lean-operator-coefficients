# First Covariant Candidate Test

The user authorized continuing toward a concrete protection candidate.
Test an ordinary complex-linear charge-reversing residual transformation first:
its induced unbroken-gauge automorphism sends a specified probe to its inverse.
Keep the positive SM dual-index condition and residual-invariant symmetric mass.

Prove character invariance under the normalizing residual transformation on the
actual radical. At an inverse probe, the dual-character identity gives equality;
a nonzero positive target dual character there is therefore incompatible.
This is a scoped candidate rejection, not a classification of all SU(6)
automorphisms, anti-linear CP, or non-split gauge extensions.

Stop before building Lorentz/BNV support for a candidate already excluded by its
light-spectrum condition. Do not claim a Hom-zero protecting solution. Persist
strict audits and run focused/full builds and layout/link checks.
