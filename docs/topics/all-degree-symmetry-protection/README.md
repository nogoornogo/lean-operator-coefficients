## Endpoint And Scope

Extend the existing derivative-free, all-degree completeness framework with
usable symmetry-protection conditions. The four previously studied sectors
are examples, not an exhaustive inventory. Treat arbitrary signed B/L changes
and specified flavor changes within supplied finite species alphabets.

The first proof endpoint is a mixed-statistics, degree-uniform protection
interface and exact character selection rules, connected to the existing
constructed residual quotients. Subsequent literature-guided stages assess
bosonic friendship and spurion evaluation under separately audited hypotheses.
See the [staged plan](plan.md) and [source register](references.md).

Finite-dimensional field representations are acceptable when needed by a
stage, but do not impose them on existing coefficient-space decomposition. Finite degree
bounds are intermediate interfaces, not a uniform all-degree cutoff.
No derivatives, EOM/IBP, matching, rates, RGE, lattice, simulation, dependency
changes, or arbitrary-group decision algorithm are included.

## Deliverables And Acceptance

1. Freeze the action/charge/flavor dictionary and distinguish all-degree
   coefficient products from finitely supported polynomial interactions.
2. Prove symmetry enhancement/protection comparison and all-degree character
   obstruction, including mixed Bose/Fermi statistics and bounded compatibility.
3. Assess the bosonic friendship theorem and spurion evaluation in one bounded
   feasibility pass each; implement only routes within the frozen interfaces.
4. Persist strict audits and verification; document exact proved scope and
   unresolved literature-to-Lean bridges without assumed spanning claims.

A precise feasibility stop for a later literature stage is an acceptable
outcome for that stage, not proof of friendship or saturation. No automatic
new invariant-theory or algebraic-geometry foundation is authorized.
