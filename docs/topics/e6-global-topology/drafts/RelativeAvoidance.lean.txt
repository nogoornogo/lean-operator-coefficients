/-!
# Relative avoidance for the E6 candidate

R4 (Lemma 7) requires: given a continuous map from a disk (or square) to the
group G that avoids the singular locus G \\ G_reg, we can extend it to a
larger disk while preserving the boundary.  This is the key homotopy-theoretic
input for proving that the fundamental group of the candidate is trivial.

This file defines the regular locus in G (`regularLocusG`) and states the
relative avoidance property.  A formal proof requires the general topology of
proper maps, covering space theory and disk deformation retractions that are
not yet fully available in the current codebase.  However, the key topological
infrastructure (`IsCoveringMap`, `IsProperMap`, `SimplyConnectedSpace`) is
available in mathlib and the proof strategy is outlined below.
-/

/-! ## The regular locus in G

In the compact identity component `G = compactIdentityComponent`, the maximal
torus `T = Torus.subgroup` is self-centralizing (`centralizer_eq`).  An element
of `G` is **regular** if its centralizer equals `T`.  Equivalently, `g` is not
contained in the centralizer of any element of the torus (except itself).

The regular locus `G_reg` is an open dense subset of `G`.  Its complement
`G \\ G_reg` (the singular locus) has codimension at least 3 in `G`, which
allows maps from 2-disks to avoid it.
-/

/-- An element `g` of `compactIdentityComponent` is regular if its centralizer
equals the maximal torus `Torus.subgroup`.  This is the standard definition:
`C_G(g) = T`. -/
def isRegularInG (g : compactIdentityComponent) : Prop :=
  Subgroup.centralizer ({g} : Set compactIdentityComponent) = Torus.subgroup

/-- The regular locus in `G` as a set. -/
def regularLocusG : Set compactIdentityComponent :=
  {g | isRegularInG g}

/-! ## Relative avoidance property

R4 (Lemma 7) states: given a continuous map `f : D → G` from a disk `D`
(or more generally a compact 2-dimensional CW complex) that maps entirely
into `regularLocusG`, we can extend it to a larger disk `D' ⊇ D` while
preserving the boundary: `f'|_D = f` and `f'(D' \\ D) ⊆ regularLocusG`.

This is equivalent to: the inclusion `regularLocusG → G` has the homotopy
extension property for 2-disks, which follows from the fact that
`G \\ G_reg` has codimension ≥ 3.

The proof strategy (following Raghunathan):
1. `regularLocusG` is open and dense in `G`.
2. The map `q : G/T × T → G` given by `(gT, t) ↦ g*t*g⁻¹` is a covering map
   over `regularLocusG` (Lemma 8).
3. The projection `G → G/T` is a fiber bundle with fiber `T`.
4. Since `π_1(T) = 0` (the torus is simply connected), the long exact
   homotopy sequence gives `π_1(G_reg) → π_1(G) → 0`.
5. The relative avoidance follows from the fact that `G \\ G_reg` has
   codimension ≥ 3, so `H^*(G \\ G_reg) = 0` in dimensions < 3.

The formal proof requires:
- `IsProperMap` for the projection `G → G/T` (available)
- `IsCoveringMap` for `q : G/T × T → G` (available)
- Homotopy lifting property for covering maps (available in `Topology/Homotopy/Lifting.lean`)
- The fact that `π_1(Torus.subgroup) = 0` (available from `CompactPathConnected.lean`)

The statement below records the proposition; a complete formal proof is
recorded as a future target.
-/
