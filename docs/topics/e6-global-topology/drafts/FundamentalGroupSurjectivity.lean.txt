# Surjectivity of the fundamental group map (L8 / R7)

The endpoint of the E6 candidate proof is:

```text
Function.Surjective GUT.E6.Minuscule.Torus.fundamentalMap
```

where `fundamentalMap : π₁(T) → π₁(G)` is the map induced by the
torus inclusion `T → G`.  Since `π₁(T) = 0` (the torus is simply
connected, proved in `CompactPathConnected.lean`), surjectivity of
`fundamentalMap` implies `π₁(G) = 0`, i.e., `G` is simply connected.

This file states the surjectivity proposition and records the
infrastructure required for its proof.  The proof of Raghunathan's
Proposition 38 requires:

1. **Quotient fibration lifting:** The bundle `G → G/T` with fiber `T`
   has the homotopy lifting property (it is a fiber bundle).
2. **Low-degree exactness:** From the fibration `T → G → B` and
   `π₁(T) = 0`, `π₁(B) = 0`, we get `π₁(G) = 0`.
3. **Global section:** A continuous section `B → G` of the quotient
   map `G → B` (or at least a lift of a given map `B → G/T` to `G`).

The formal proof requires mathlib infrastructure that is not yet fully
available.  The relevant existing declarations are noted below.
