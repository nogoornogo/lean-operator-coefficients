/-!
# Simply connectedness of the coset space

R6 (Proposition 37) states: the coset space `B = G/T` is simply connected.
This is the key topological input for proving that the fundamental group of
the candidate is trivial (via the induced map `pi1(T) → pi1(G)`).

The proof uses:
1. The conjugation cover `q : B × T → G` (Lemma 8, L6)
2. Relative avoidance: disk deformations avoiding the singular locus (Lemma 7, L5)
3. Path connectedness of `G` and `B` (R0, L1)
4. The homotopy lifting argument to show `pi1(B) = 0`

This file states the simply connectedness result and records the dependencies.
A formal proof requires the full compact group structure and the conjugation
cover map which are not yet available.
-/
