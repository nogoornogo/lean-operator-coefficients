## Frozen first endpoint

Determine whether changing Yukawa coefficients in the existing scalar/VEV
family can remove the standard ten-dimensional fifteen components from the
actual light space. Use the exhaustive five-coupling image and exact radical
equations already proved. Prove a concrete universal light-inclusion result
for every admitted Yukawa and an exact-radical obstruction for proposed light
spaces omitting one of those named components.

This is a screening result, not yet qque prohibition or a full protecting
model. The standard embedding, 15+bar6+bar6, existing scalar multiplet,
fixed vacuum and zero bare mass remain fixed. A finding that this family
cannot change the relevant placement is a valid stopping result.

## Staged plan

1. Screen the existing generated mass family rigorously; changing only
   couplings or bar6 mixing must not be mistaken for escaping the prior result.
2. Record what this excludes and what still requires a genuinely different
   scalar/VEV family, carrier or residual action. Choose no arbitrary new
   representation solely to bypass the theorem.
3. If an explicit candidate is supported by existing inputs, specify its
   genuine group action, invariant symmetric mass and actual light dictionary
   before using the prohibition/mixed-request APIs. qque prohibition alone
   is not all B1 prohibition.
4. Stop for a model-input scope decision if escaping the screened class
   requires new scalar representations, a new vacuum or a larger carrier;
   do not recursively begin their classification.
