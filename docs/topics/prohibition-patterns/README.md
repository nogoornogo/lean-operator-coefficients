## Frozen Endpoint

Provide a 12-row catalogue, not the Cartesian product of all targets and
hypotheses. Five generic patterns reuse admitted-factor, semisimple, scalar,
cyclic and restriction criteria. Four target connections cover absolute B1,
B2, L2 and explicitly prescribed LFV dipoles. Three controls cover arbitrary
selected combinations, empty selection and neutral zero carriers.

Add a generic cyclic scalar iff, an arbitrary chosen subset of the three B/L
specifications on the same SM/Higgs input, and a joint B/L-plus-prescribed-LFV
predicate. LFV uses its actual separate dipole coefficient domain; do not
claim one selector captures all flavor violation or encode it as total L.
No new model admission, local saturation, exhaustive UV search or nonzero
carrier foundation is requested. Preserve dependencies and physics boundaries.

Stop when these bounded interfaces, audited connection/control examples,
English catalogue, assumptions and verification pass. A missing model-specific
carrier witness is a documented connection gap, not authority to start a new
foundation. Existing Koren/BGW, LLHH and DGT certificates are references;
no new paper-wide verification is requested.

See [plan](plan.md), [catalogue](catalogue.md), [references](references.md) and
[verification](verification.md). Root README emphasis is unchanged.

## Result

The twelve-row catalogue is implemented with explicit prerequisites and
connection gaps. Cyclic prohibition has a checked nonzero-charge iff under
Nontrivial admitted scalar action. Arbitrary subsets of B1/B2/L2 share one
input; prescribed LFV families combine by conjunction on their actual domain.
Koren, BGW and same-UV-group DGT controls are audited. No new admission
foundation was needed. The frozen stop condition is reached.

User-authorized master integration completed at stage 01 as `checkpoint 01`.
