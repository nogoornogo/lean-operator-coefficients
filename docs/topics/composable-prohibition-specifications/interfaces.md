# Usage Contract

1. Admit the field alphabet and local/residual action once, using existing
   model interfaces or a separately proved field dictionary.
2. Build a stable detector: charges are one option, not the definition of
   every physical selection. Specify the target predicate and signed conventions.
3. Form union for simultaneous prohibition of several classes. Intersection
   selects simultaneous changes within one operator.
4. Use `ComposableProtection` to obtain the vanishing or symmetry-extension
   criterion on the actual selected input. Supply actual scalar action and
   detection facts when applying charge selection.
5. For prescribed flavor matrix elements, keep one coefficient domain and use
   `CoefficientSelectorComposition.combine`; use the dipole adapter for its
   admitted domain. A family of prescribed pairs is not automatically all LFV.

For SM B/L targets, use `ComposableBLSupport.specification t`; replacing t
leaves the field/action dictionary fixed. The integer first coordinate is 3B,
so absolute Delta B=1 corresponds to 3, not 1. The boson alphabet is the
existing Higgs/gauge-dual scalar alphabet, with both B/L labels zero.

The charge criterion does not discover an arbitrary symmetry, prove anomaly
freedom, derive masses or establish UV generation. General symmetry extension
still requires residual restriction surjectivity. Content support and linear
selectors remain different interfaces with different semantic obligations.
