## Endpoint

Reuse one admitted field/action input across different prohibition questions.
Compose stable content specifications and independently supplied coefficient
selectors, then connect them to the existing coefficient-space decomposition,
symmetry-extension criterion and charge selection rules. Changing a target
predicate must not require re-proving the field dictionary.

The initial physical regression uses the existing signed SM BNV field input.
It establishes reusable content selection and a simultaneous B/L specification;
it does not build a protecting UV model or classify every LFV channel.
See the [results](results.md), [interfaces](interfaces.md),
[frozen plan](plan.md), [source register](references.md) and
[verification record](verification.md).

## Boundaries

All documentation is English. No dependency changes, derivatives, EOM/IBP,
generic saturation, mass-basis construction, UV matching or rates are included.
Mass/light-field data stay in their existing model interfaces. A precise
adapter feasibility stop is acceptable if a missing physical dictionary would
require a separate foundational project.

The unrelated untracked `docs.zip` existed at planning start and is preserved.

## Completed Endpoint

Specification/selector composition and the actual SM B/L regression are proved.
The bounded dipole adapter succeeds on its existing dedicated coefficient
space. No new mixed-field dipole embedding or foundational stop is needed
within that route. General UV model search and automatic all-LFV identification
remain outside scope. The result is a reusable condition/certificate interface,
not a newly discovered protecting model.
