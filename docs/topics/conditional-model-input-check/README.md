## Frozen scope

A one-pass conditional input review of the ten candidate groups below using
existing exact algebraic coefficient interfaces. A pass can close with a
new proved consumer, reuse of an audited certificate with explicit unchanged
inputs, a counterexample to a proposed inference, or a documented missing
input/interface. No claim of complete physical models, generated interactions,
proton lifetimes or a classification beyond the declared coefficient domains.
