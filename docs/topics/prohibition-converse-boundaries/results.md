# Four-Stage Outcome

| Stage | Outcome | What remains outside the certificate |
|---|---|---|
| [LFV](lfv-results.md) | Exact allowance/prohibition criterion for arbitrary selectors on finite diagonal cyclic modules | General nonabelian/nonsemisimple weight reduction |
| [Surplus](surplus-results.md) | Actual light exterior counterexample to the proposed numerical converse | Classification of masses and actual product constituents |
| [Copy constraints](copy-mass-results.md) | Exact existence iff for an SM radical in the fixed full-SM 10/bar5/40/50 dual-copy family | UV-invariant action, VEV realization and residual protection |
| [All degrees](all-degree-results.md) | Exact criterion guarded by actual carrier support, transported to SM; raw-filter necessity refuted | Computable full parameter/support classification |

These outcomes have different logical meanings. LFV and mass existence gain
bounded iff theorems. Surplus gains a counterexample instead of a false converse.
All-degree charge detection becomes exact when restricted to actual supported
carriers; removing that support condition is disproved. No new protecting
UV model is obtained and no finite-table survivor count is changed.

The four [frozen contracts](plan.md) reached their stated endpoints. The
all-degree support-classification gate is the remaining user scope decision;
no new foundational project was started. See [proof dossier](../../proof/current/applications/Physics/PROHIBITION_CONVERSE_BOUNDARIES.md),
[source register](references.md) and [verification](verification.md).
