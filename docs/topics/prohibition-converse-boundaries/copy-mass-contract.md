# Frozen Copy/Mass Existence Contract

Retain ActualFullFamilyIndex.fields p q on the existing full SM covering group.
For all natural counts p,q and N, prove

    (exists B : SymmetricMass (fields p q),
       Nonempty (Equiv B.radical.toRepresentation (copies N smGeneration)))
    iff (p0-q0=N and p1-q1=N in integers, p2=q2, p3=q3).

Construct the reverse using an explicit equivalence from source p to
(copies N smGeneration) x source q, an evaluation-pair mass on source q and
its dual, and equivariant pullback to the unchanged original fields. Prove
copy-index rearrangement rather than assuming a dimension/character match.
N=0 is included. The action is full SM only, not a claimed SU(5)-invariant
completion. A balanced positive-generation vectorlike example with zero mass
will control the distinction between existence of one suitable mass and every
mass. Stop at this exact family and algebraic invariant-mass existence.
