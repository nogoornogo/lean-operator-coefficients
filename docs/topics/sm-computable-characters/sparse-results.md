# Sparse characters and the 107 neutral rows

This records checkpoint `checkpoint 01`. The subsequent
[kernel refinement](kernel-results.md) preserves its semantics and revisits
the arithmetic stopping boundary.

The sparse refinement preserves the actual character and conditional support
semantics of the reference evaluator. It also evaluates all 107 previously
unclassified constant-species neutral rows without expanding individual
exterior subsets. The [continuation plan](sparse-plan.md) fixes this scope.

## Uniform semantic proof

`Math.SparseWeightPolynomial` merges equal keys by adding integer coefficients,
multiplies lists by merged shifts, and shares the predecessor exterior-degree
table in the include/exclude recurrence. Multiplication puts the shorter list
in the outer fold. Evaluation preservation holds without an ordering or
uniqueness premise on the input lists. Formal monoid-algebra evaluation then
recovers coefficient equality. Sortedness affects efficiency, not soundness.

`SMSparseCharacter` uses six integer tuple keys, with proved inverse conversions
to the existing six-coordinate weights. The exterior, source, Higgs and cached
terms have the same coefficients as the reference construction, for arbitrary
mixed contents and Higgs constituents. `presents`, `polynomial_reference`,
`multiplicity_reference` and `cached_multiplicity` require no literature input.
No spectral basis, weight table or equality of algorithms is assumed.

`SMSparseSupport` transports actual kernel dimension, rank and local support.
`SMSparseQLSupport` transports the existing scalar q/l entry test and original
Higgs support criterion. These consumers retain exactly the existing explicit
Weyl `TorusReduction` premise. The Weyl law itself is not proved here.

## Bounded numerical output

`SMNeutralSparseRanks.inputs_enumerated` is kernel-checked: the 107 explicit
inputs equal the old evaluator's unresolved entries over its original finite
constant-species domain. `solve` is executable. `kernel_dimension` and
`rank_sound` prove its uniform connection to the actual kernel and rank under
the same Weyl input, for every row, independently of an exported CSV.

[The separate output](../../../tools/exact-rank/neutral-sparse-results.csv)
records 41 positive multiplicities and 66 zeros. It is generated by exact
compiled Lean execution and compared row by row with the independently
implemented grouped-weight Python diagnostic. For example Q6,m2,delta=-2
has 5,843,376 columns, multiplicity 261 and conditional rank 5,843,115.
The Q middle exterior degree uses 11,899 distinct keys in the executable table,
instead of 9,075,135,300 repeated subset terms.

The uniform evaluator soundness proof and a proof of each closed numerical
output are distinct. Compiled output plus an independent check does not by
itself supply a kernel-checked equality for all 107 numbers. See the
[verification record](sparse-verification.md) for the arithmetic attempt and
its interruption at roughly 18 GB memory use. No all-107 numerical equality
theorem is claimed. Small sparse/cached controls in `SMNeutralSparseExamples`
are kernel-checked; no CSV is used as a theorem premise.

The original `constant-content-ranks.csv` remains unchanged: 19,160 elementary
parity/charge ranks, one nontrivial LLHH rank, and 107 unresolved entries in
that unconditional classifier. The new conditional evaluator does not remove
the Weyl input or silently upgrade the old table's theorem scope.

## Remaining boundary

Arbitrary mixed contents have a proved executable evaluator, but no exhaustive
mixed-content table or efficient full request-domain search is claimed. The
572 bounded assignments are not reclassified. Other residual classes, charged
Higgs, derivatives/EOM/IBP, multiple Higgs copies, UV realization and rates
remain outside this continuation. Dependency and Lean pins are unchanged.
