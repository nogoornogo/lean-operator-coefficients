# C5 Primary Sources and Ordered Checks

Each entry owns its comparison. A difference or formal stop in one does not
end the queue. Reference formulas guide the proof and are not its premises.

1. **Li et al., Complete Set of Dimension-8 Operators in the Standard Model
   Effective Field Theory**, [arXiv:2005.00008v3](https://arxiv.org/abs/2005.00008v3),
   Eq. (4.24), the charged-lepton `e_C` row. Compare the ordered Pauli current,
   factor i, bidirectional Higgs derivative and Higgs norm. Fix one flavor,
   ordinary derivatives and zero gauge/Yukawa couplings. Neighboring rows
   with other fermions/flavors are outside this source.
2. **Murphy, Dimension-8 Operators in the Standard Model Effective Field
   Theory**, [arXiv:2005.00059v6](https://arxiv.org/abs/2005.00059v6), Table 5,
   `Q_{e²H⁴D}`. Compare the right-chiral four-component current with the
   charge-conjugate two-component convention explicitly; do not silently
   identify a barred spinor with an unraised formal component label.
3. **Dreiner, Haber and Martin, Two-component spinor techniques and Feynman
   rules for quantum field theory and supersymmetry**,
   [arXiv:0812.1594v6](https://arxiv.org/abs/0812.1594v6), Appendix G.1,
   Eqs. (G.1.62),(G.1.67),(G.1.81)–(G.1.82) and footnote 127.
   This is a new independent convention check: block gamma/projector
   identity and the anticommuting reversed-current sign. It is not an
   independent count of the selected dimension-eight quotient.

Completeness claims require a proved full-source coefficient equivalence
in addition to matching a printed density. No validation covers full SMEFT,
Hermitian flavor counts, amplitudes, rates, running or physical matching.
