## Endpoint and motivation

Start with required SM content, admitted Yukawa signatures and prohibition,
then derive candidate cyclic charges rather than selecting an existing model
and checking it. The first family is non-supersymmetric SM x Z_k, not a simple
GUT. The bounded search uses 2 <= k <= 12, three generations with universal
charges, and one neutral Higgs doublet with its conjugate. These are declared
search restrictions, not consequences of the previous theorems.

The endpoint is an actual algebraic light-field/action construction and a
proof of derivative-free all-degree absolute Delta B=1 prohibition on the
specified SM/Higgs alphabet. A constructed invariant spectator mass should
have exactly that light radical. This is not an anomaly-free UV gauge theory,
a realistic vacuum or a simple-group completion.

The [plan](plan.md) separates charge filtering, actual admission, mass
construction and prohibition. Existing BGW/Koren/DGT examples are controls,
not the source of a hard-coded answer or claims of a new physical model.
The [source register](references.md) records every planned proof input.

## Result and stopping point

The [result](results.md) derives 572 arithmetic survivors from 649 labeled
Yukawa-parametrized pairs. The first survivor, Z2 lepton parity, has an actual
three-generation SM field action, an explicit nonzero spectator mass with
exact SM radical, nonzero physical Yukawa coefficients in all three channels,
and all-degree B1 prohibition on the declared alphabet. The construction is
a familiar classical algebraic parity input, not a newly discovered model or
an anomaly-free/exact quantum protection certificate.

The frozen first endpoint is complete. Anomaly/quantum validity, an origin for
the residual symmetry, simple-GUT lifting and realistic mass/VEV construction
require separate scope decisions. No all-degree protection or UV-realization claim is made about every survivor.
See the [reader study](../../model-studies/inverse-cyclic-sm/README.md),
[proof dossier](../../proof/current/applications/Physics/INVERSE_CYCLIC_SM_CONSTRUCTION.md)
and [verification](verification.md). Integration was subsequently authorized
and completed; see the milestone integration below. No remote push was made.
The user removed docs.zip before implementation; it was not modified here.
