# Selected LFV, B2/LLHH Properties and Generator Orbits

## Exact coefficient tests

For finite cyclic diagonal source and target flavor representations, take a
normalized source basis vector and a target coordinate projection. The
selected actual B/W dipole coefficient can be nonzero iff the two selected
charges agree. Every selected coefficient vanishes iff they differ. The
matching-charge direction constructs an intertwining matrix unit; the reverse
uses the faithful cyclic character. This is a selected dipole statement,
not a classification of arbitrary LFV selectors or generated decay rates.
In the generation-universal family all selected lepton charges agree:
this diagonal residual action alone does not forbid these transitions.

On the existing one-copy six-quark u^2 d^4 domain, universal physical quark
charge q gives prohibition iff 6q is nonzero. On the existing LLHH domain,
neutral Higgs and lepton charge l give prohibition iff 2l is nonzero. Both
neutral cases admit actual nonzero coefficients. These adapters do not extend
their domains to three generations or all degrees.

## Fixed-order equivalence

At each fixed cyclic order, multiply both q and l by the same unit.
This is a change of generator of the same cyclic group. Unit orbits form
an equivalence relation; equality of the computed orbit sets is equivalent
to this relation. Actual scalar field actions agree after the corresponding
group automorphism. The BNV, B2 and LLHH neutrality tests are preserved.
