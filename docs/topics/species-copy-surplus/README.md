## Endpoint And Scope

Replace the shared source/target restriction of the existing common-copy inlet
with species-dependent representations and an explicit surplus for one common
irreducible constituent. Derive common kernel splits and a nonzero physical qque
coefficient on actual participating light ranges. Retain arbitrary groups and
explicit mass/action conditions. See the [frozen plan](plan.md).

The motivating [model evaluation](../proton-protection-model-checks/evaluation-result.md)
is integrated into master. This topic is a general algebraic extension; SU(5)
and Pati–Salam are illustrative dictionaries, not theorem parameters. Whether a
permitted coefficient is generated is excluded from this topic.

## Deliverables And Acceptance

1. A shared mathematical surplus-to-kernel theorem for unequal species sources
   and targets, with source semisimplicity but no target semisimplicity/topology.
2. An actual-mass physical bridge deriving light support and exterior qque.
3. A generic specified-SM-sector normal-form constructor deriving mass squares
   from arbitrary invariant symmetric mass under explicit pairing conditions.
4. Unequal-copy and disjoint-constituent controls, strict persisted audits,
   proof dossiers and assumptions updates at verified milestones.
