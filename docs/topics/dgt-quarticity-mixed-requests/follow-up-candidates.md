# Follow-Up Candidate Search

Search date: stage 01. Literature preflight only, not a Lean certificate,
new proof endpoint or authorization to expand the current topic. Non-SUSY
inputs were prioritized. Search phrases included "non supersymmetric discrete
symmetry forbid proton decay allow neutron antineutron oscillation" and
"Dirac neutrinos Z3 Weinberg residual symmetry model". Existing BGW, Koren,
DGT and quarticity examples were excluded as new candidates.

## 1. Dev–Mohapatra: B1 Forbidden, B2 Allowed

*A TeV Scale Model for Baryon and Lepton Number Violation and Resonant
Baryogenesis*, [arXiv:1504.07196v2](https://arxiv.org/abs/1504.07196v2),
[PDF](https://arxiv.org/pdf/1504.07196v2),
[publication](https://doi.org/10.1103/PhysRevD.92.016007).
Inspected Sec. II Eq. (1), Sec. III Eqs. (3)-(5), and text following Eq. (4).
The PDF header and arXiv history identify v2, 5 June 2015.

Source observations: quarks, N and inert eta are Z2-odd; SM leptons/Higgs and
chi are even. The paper exhibits six-quark B2 interactions and a distinct
eta-containing B1 interaction. Antisymmetric down-flavor couplings require
different down families. Thus the SM/Higgs-only restriction and the enlarged
alphabet cannot share an unqualified B1 prohibition claim.

Proposed bounded formal input (not proved here): establish all-degree
SM/Higgs B1 prohibition, actual selected six-quark allowance, and actual
LLHH allowance under the printed parity. The six-quark and LLHH existing
interfaces are candidate reuse routes; parity neutrality alone is inadequate.

Repository assessment: medium burden. A two-down-flavor six-quark witness
and printed-operator semantic bridge need checking; a one-generation witness
would not certify the paper's antisymmetric coupling channel. No loop matching,
oscillation time, neutrino mass generation or baryogenesis should enter the
endpoint. A selected eta-dressed B1 witness is an optional later domain control,
not a required full-alphabet foundation.

Priority: first. It tests allowance of B2, absent from the current mixed examples.

## 2. Ma–Pollard–Srivastava–Zakeri: Majorana Forbidden, Dressed Allowed

*Gauge B-L Model with Residual Z3 Symmetry*,
[arXiv:1507.03943v2](https://arxiv.org/abs/1507.03943v2),
[PDF](https://arxiv.org/pdf/1507.03943v2),
[publication](https://doi.org/10.1016/j.physletb.2015.09.010).
Inspected pp. 2-3, Eqs. (1)-(6). PDF header and arXiv history identify v2,
16 July 2015.

Source observations: all leptons and chi2 transform with the same nontrivial
Z3 phase; Eq. (5) includes chi2 NL NL and chi2 NR NR. Bare Majorana bilinears
are excluded by the residual symmetry, while scalar-dressed bilinears occur.
The paper also supplies Dirac-sector Yukawa terms.

Proposed bounded formal input (not proved here): bare singlet exterior-square
prohibition plus chi2-dressed allowance; optionally the SM/Higgs L2 restriction.
An actual Dirac Yukawa coefficient would require a separate adapter. Charge
normalization and the residual subgroup's action on fractionally charged quarks
must be established before making any joint baryon claim.

Repository assessment: low-to-medium burden for the bare/dressed singlet
restriction, using the quarticity determinant/actual-action construction with
Z3 phases. This is an assessment, not an existing semantic equivalence. No
full model, anomaly, residual-gauge/global identification, vacuum dynamics or
dark-matter lifetime is certified. Do not infer B1 prohibition from the title.

Priority: second. Independent source, but its bare/dressed pattern overlaps
with quarticity more than candidate 1 expands coverage.
