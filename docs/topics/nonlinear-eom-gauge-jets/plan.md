# Frozen Nonlinear EOM And Formal Gauge Contract

## Stage 1: Polynomial EOM

Over a commutative complex algebra with specified ordinary derivations, form
the ideal generated by all finite derivative words of a specified set of
polynomial equations. Prove minimality, derivative stability, onto quotient,
exact projection kernel, descended Leibniz derivatives and commutation when
the supplied ordinary derivatives commute. Compare EOM followed by the actual
linear divergence quotient with the off-shell quotient by EOM plus divergence,
in both directions, including inverse coefficient transport. IBP is not
ideal-closed. Finite off-shell subspaces have finite quotient images; no
global field-number grading is asserted for nonlinear equations.

Recover the existing scalar linear equation ideal as a specialization. Build
one neutral four-direction scalar consumer with signature (+---), equation
`box phi + lambda * phi^3 = 0`, every ordinary derivative descendant, a
nontriviality control from zero-field evaluation, and the formal identity
`kinetic = lambda * phi^4` modulo EOM and IBP. Generic symmetry descent must
state its stability inputs explicitly; this is a polynomial source model,
not a theorem deriving the EOM from an analytic variational principle.

## Stage 2: Connection And Curvature

In a unital associative algebra with commuting ordinary linear derivations,
define `nabla_i x = partial_i x + [A_i,x]` and
`F_ij = partial_i A_j - partial_j A_i + [A_i,A_j]`. Prove Leibniz,
antisymmetry, `[nabla_i,nabla_j] x = [F_ij,x]` and cyclic covariant Bianchi
directly from the supplied ordinary derivation laws and associativity.
Instantiate the ordinary derivations entrywise on finite matrices over the
existing scalar jet algebra. Exhibit an actual two-by-two noncommuting
connection control. These are formal adjoint matrix connections; arbitrary
Lie-group bundles and analytic local gauge transformations are not premises
or claimed outputs. Constant conjugation covariance may be proved using
explicit derivative-constant inverse matrices.

## Stage 3: Formal Yang–Mills Consumer

Use all ordered matrix connection components as ordinary jet generators in
four dimensions. Define curvature and the source-free equation
`E_nu = sum_mu s_mu * nabla_mu F_mu,nu`, with `s = (1,-1,-1,-1)`.
Its entries are actual nonlinear polynomial equations, not external EOM or
covariance assumptions. Form their full differential ideal using Stage 1.
Prove all ordinary descendants and covariant descendants vanish entrywise,
the constructed curvature/Bianchi identities, zero-field nontriviality, and
instantiate onto/kernel and inverse EOM/IBP comparison. Preserve finite-image
interfaces without assuming a field-number direct-sum decomposition.
This is a formal matrix model, not yet an SU(N) traceless/real-form, local
gauge-invariant operator classification or a Lorentz-equivalence dictionary.

## Routes And Stop Conditions

Primary routes: explicit derivative-word ideals and surjective derivation
transport; associative commutator identities; entrywise matrix derivatives.
Fallbacks for the same statements: smallest stable ideal by intersection;
finite component expansion for matrix identities. Investigate at most these
two routes per foundation. A new theorem-level prerequisite beyond them is
a documented scope stop, not permission to assume the desired identity or
silently drop a contracted consumer. Continue through all three stages unless
an actual scope/authority or bounded feasibility stop occurs. A coherent
checkpoint alone is not a stop.

Keep all pins and default Lean heartbeat/recursion/kernel limits unchanged.
Serialize heavy checks with four Lean threads, 540 seconds per command and
an inherited 16 GiB per-process address-space guard. Require focused builds,
persistent strict transitive standard-axiom/import audits, full `lake build`,
aggregate/layout, links, topic index, metadata and diff checks. Reconcile the
literature list and assumption/proof records, review and commit the endpoint.
Leave the verified child available for review; master integration and remote
mutations are excluded.

Excluded: mixed nonlinear fermionic equations, general normal-form/PBW or
Hilbert-series counts, analytic Euler–Lagrange dynamics, potential/gauge exactness,
arbitrary local gauge transformations, global bundles/topology, physical
amplitudes/rates, matching, RGE, nonperturbative QCD and numerical evolution.
