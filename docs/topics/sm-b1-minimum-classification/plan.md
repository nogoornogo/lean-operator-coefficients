# Frozen complete-exclusion attempt (stage 01)

## Input and statement

Reuse the existing Lean-owned 572 assignments and their exact all-degree
B1 classification. For each of the 326 allowed rows, seek an
`SMMinimumOperatorDimension.IsMinimum q l 3 M` certificate. M is twice
engineering dimension, `3*n+2*(h+d)`. The bound covers every actual allowed
original content with absolute B3=3, both signs and all Higgs bidegrees.
The 246 forbidden rows do not receive a numerical minimum.

Keep fixed ten signed three-generation SM species, derivative-free exterior
statistics, independent Lorentz actions, one residual-neutral Higgs/dual,
scalar cyclic q/l actions, pins/options and the strict axiom boundary.
No arbitrary residual action, B2 extension, UV model, rates, derivatives,
EOM/IBP or general all-k minimum classification is requested.

## Stage 1: complete interval inventory before gap work

Extract all 18 existing B1 charge-family witness grades and the four newer
small witnesses. Filter by each row's actual congruences; the least grade
among these is a proposed upper bound until reconnected to an actual original
space at that grade. Obtain lower bounds from the existing minimum-|L|
theorem, below-ten criterion and charge/hypercharge envelope. Reuse original
even-degree and existing parity filters where applicable.

Produce the full 326-row gap inventory with exact/interval counts, maximum
upper bound, widths and distinct signed charges required. Retain a standard
library Python diagnostic and its conventions; its output is not a premise.
Prove the final interval semantics and aggregate classifications in Lean.
Do not infer a prohibition from a search miss or a guessed witness.

## Stage 2: at most two bounded routes

**A: shared symbolic bounds.** Strengthen lower bounds using ordinary
finite-species inequalities and existing charge, hypercharge, parity,
capacity and joint-support consequences. Reuse existing finite/minimum APIs
and original-space bridges. Prove exact certificates when an actual witness
attains such a bound. Do not presume minimum |L| chooses the cheapest signed
charge or the cheapest content.

**B: explicit witnesses and bounded gap closure.** After recording Stage 1,
try at most one new explicit balanced-occupation/first-live-branch template
for each of the 18 normalized odd charges from -17 through 17. The changed
template must keep actual joint color/weak/both-spin statistics; an existing
family may remain the upper bound if the new proposal fails. Use existing
semantic decisions only, no new reflection engine. Candidate inspection
uses finite dictionary arithmetic, not a general optimizer. Before testing,
record each proposed content and grade. No repeated occupation/branch search.

For remaining gaps permit symbolic charge-level exclusions using the same
interfaces. Do not exhaustively enumerate arbitrary content/occupation/color
spaces. If a gap requires that enumeration, a new representation theorem,
a new compiled solver or a second witness-search pass, stop and report it.
This cap is deliberate: Stage 1 must determine whether complete exclusion
is economical before a larger computational program is authorized.

One pass over A and B. There is no implicit continuation into broader
foundation or evaluation redesign. A failed route cannot restart its budget
under a renamed topic. A partial outcome retains all proved bounds and
explicitly marks the full 326-minimum endpoint unachieved.
