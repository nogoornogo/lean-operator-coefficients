# Additional SU(5) Mass Families — Frozen Scope

Authorized at stage 01 by the request to check other mass models. Continue
on `proof/su5-matter-mass-protection`, base/target unchanged; no merge authorized.

## Family And Endpoint

Use actual `(10 + bar5 + 10) + bar10`, with standard SM-cover action.
Both tens have the same genuine scalar residual character chi of finite
Abelian H; bar-five has an independently supplied genuine character psi.
The dual-ten has the dual of the target-ten action. H is trivial on spinors.
This is a bounded residual class, not arbitrary flavor or compensated mixing.

For each ten species Q, uc, ec, allow an independent complex mass row
(alpha,beta) into the corresponding target species. Pair by the canonical
symmetric Dirac evaluation mass. The mass needs SM/H invariance, not UV-SU5
invariance or a supplied UV Yukawa origin. Use actual exterior-square branching
and explicit equivariant kernel maps; do not import finite-script answers.

Prove that every species has an injective light embedding, choosing the
original copy when its row is zero and otherwise the kernel line
(beta,-alpha). Derive rather than assume light membership and residual action.
Transport the named physical nonzero qque exterior coefficient to their ranges.
Cover common rows, species-dependent rows, zero rows and partial masses.
Exhibit a nonzero mass and a different-copy mixed control. Do not infer exact
full spectrum from only those embeddings; prove any claimed radical statement.

## Gates

Freeze APIs after source inspection. A missing kernel/field transport requiring
new foundations is a stop gate. No arbitrary irreps, new scalar sectors,
non-Abelian residuals, dependencies, matching or rates. General compensated
copy actions remain outside this family. Complete focused/full builds, strict
transitive audits, layout/link/diff checks and the existing exact controls.
Record statements and limitations, review and commit the verified checkpoint.
