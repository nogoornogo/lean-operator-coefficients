## Endpoint And Scope

Generalize the constructive connection between a model's supplied algebraic
data and the existing coefficient inputs: actual field representations,
chirality/conjugate conventions, exact selected fields and interaction
symmetry. Reuse the current nonderivative, derivative/EOM/IBP and local-density
interfaces through additive adapters. Published interfaces stay available.

The finite endpoint covers finitely many field species, finite-dimensional
complex internal carriers and supplied complex-linear symmetry actions.
Jet sources retain their existing all-order scope. Generic lemmas may avoid
finiteness where unused. Representation decomposition, analytic mode solving,
vacuum discovery and empirical viability are not automatic outputs.

The [results](results.md) and [proof dossier](../../proof/current/inputs/Physics/FIELD_CONNECTIONS.md)
describe the shared constructions. The [input guide](input-guide.md) gives
entries and execution commands. The [implementation plan](plan.md) retains
