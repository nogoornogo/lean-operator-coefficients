# Independent Species Surplus Recheck

Keep the minimal pre-EW dictionary from
[2211.02054v2, Sec.II Eqs.(1),(2),(10)](https://arxiv.org/abs/2211.02054v2).
For H=1 each selected Q/uc/ec source is one trivial copy and has no opposite
charged partner: 1→0 for all three. The common trivial irreducible R has Hom
surplus (1,1,1). No source self/rest pairing exists because none of the remaining
fermions has opposite selected hypercharge. Gauge irreducibility supplies the
copy factorization required by the general constructor.

Thus [the new theorem](../../topics/species-copy-surplus/result.md) derives
actual charged light ranges and physical qque permission for every invariant
symmetric mass on this supplied SM carrier. The neutral nuc/xi sector can have
arbitrary invariant symmetric entries, including Majorana masses and singular
choices. Its invertibility is not an admission condition.

If the optional accidental U1_B is imposed, the all-left copy weights (Q,uc,ec)
are (1,-1,0) in units 3B. Each source is scalar, so no nonzero irreducible can
map into all three. Independent sources do not repair this obstruction. The
optional action and the gauge-only dictionary are distinct questions.

The positive admission is still conditional on the literature branching/action;
no new Lean PS carrier, stabilizer or global descent adapter is claimed. The
paper's higher interactions and their matching are not checked by this theorem.
