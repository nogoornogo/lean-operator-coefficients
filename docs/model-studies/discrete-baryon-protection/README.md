# Baryon triality and proton hexality: component restrictions

The source charge convention is [hep-ph/0512163v2](https://arxiv.org/abs/hep-ph/0512163v2),
Eq.(2.17): n=0,m=p=1 for baryon triality and n=0,m=5,p=2 for proton hexality.
Concrete FN realizations are supplied in [hep-ph/0610026v1](https://arxiv.org/abs/hep-ph/0610026v1)
and [0708.0989v1](https://arxiv.org/abs/0708.0989v1). Their complete UV parameter
assignments and spectra are not certified here.

For baryon triality, the declared physical Q,uR,dR,L,eR,H charges are
(0,1,-1,-1,-2,1) modulo three. Lean constructs their actual scalar actions
on arbitrary complex multiplicity modules and proves all-degree absolute B1/B2
prohibition, including Higgs/dual insertions and statistics. The Higgs is charged.

For proton hexality, inverting the source generator gives the existing BGW
SM/Higgs dictionary modulo six. The finite component equality is kernel-checked;
the existing actual-action BGW prohibition certificate applies to this normalized
input. No neutral-Higgs theorem or superpotential dimension is substituted.

Only the ordinary SM fermions and a supplied single light Higgs are retained.
Identifying that Higgs from Hu and conjugate Hd, excluding superpartners and
connecting the FN realization to this restricted input remain model obligations.
LLHH charge neutrality is checked but is not promoted to an existence theorem
in these new restricted model comparisons.
