# Two Non-Supersymmetric Selection-Rule Controls

The [verified application record](../../topics/flavor-quarticity-controls/results.md)
compares two different boundaries of symmetry protection.

| Explicit input | Prohibition | Constructed nonzero control |
| --- | --- | --- |
| DGT m=1,n=3, Circle action on selected dipoles | Prescribed muon-to-electron and muon-to-tau B/W coefficient selectors vanish | After restriction to Z9 each pair has an actual coefficient with selected value (1,0) |
| DGT residual Z9, existing signed SM/Higgs alphabet | Absolute Delta B=1,2 at every derivative-free degree | No existence claim on other baryon sectors |
| Quarticity Z4 times Z2, one right-handed neutrino | Every bare exterior-square coefficient vanishes | A coefficient on exterior-square tensor eta evaluates to one |
| Quarticity, original SM/Higgs-only alphabet | Absolute Delta L=2 at every derivative-free degree | No contradiction with the extended neutrino/eta witness |

The DGT case uses a proved restriction of actual representations and a flavor
Hom map that is not surjective. The quarticity case demonstrates field-domain
dependence: a charged scalar compensates the forbidden fermion-pair charge.
These are coefficient-space statements. Nonzero means not symmetry-forbidden;
it does not mean generated by UV matching or an observable process.

Sources are [DGT 2202.05275v2](https://arxiv.org/abs/2202.05275v2), Tables I–II,
Secs. II–III, and [quarticity 1606.04543v1](https://arxiv.org/abs/1606.04543v1),
Table I and Sec. II. The first certificate restricts the model to SM/Higgs and
specified dipole domains; the second admits only the selected nuR/eta fields.
Neither certifies a complete model, anomaly freedom, physical masses or rates.
