# Triplet-breaking left-right input

Fix the Section II input of [1507.01584v3](https://arxiv.org/abs/1507.01584v3),
Eqs.(1)–(3) and footnote 1: ordinary left/right quark and lepton doublets,
a B-L-neutral bidoublet and a right triplet of B-L charge -2 whose neutral
component has a VEV. Extra dark multiplets are outside the tested alphabet.

With X=3(B-L), the supplied SM projection has Z6 charges 1 for quarks and -3
for leptons. The source also notes the Z6 subgroup behind the usually emphasized
Z2 parity. Existing neutral-Higgs consumers prove B1 permission with minimum derivative-free
dimension six, uR²dR⁴ allowance and LLHH allowance on that projected input.
Thus the supplied residual action alone does not prohibit those sectors.

The [bidoublet continuation](../../topics/conditional-model-input-check/bl-lr-results.md)
constructs an actual equivariant positive-column Higgs inclusion and retraction.
For an SM-stage quadratic operator whose negative column has nonzero eigenvalue
and positive column has zero eigenvalue, its entire kernel is that one doublet.
The kernel representation and its dual match the existing SM Higgs and dual;
the residual X subgroup is neutral on them. SM covariance of the constructed
quadratic operator is proved.

The displayed eigenvalue condition is explicit external selection data; it
is not derived from a full LR scalar potential. Physical fermion mass-radical
maps, generic Higgs mixing, the full stabilizer/faithful quotient and the heavy
spectrum remain outside the result.
