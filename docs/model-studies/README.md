# Model Studies

Model-specific applications and bounded explorations are separate from the
project's selected main theorem. Each study states its model inputs, established
results and limits. A completed or stopped exploration remains a model study;
its placement does not imply a general classification or a physical prediction.

## Model View and Literature View

The organizing unit here is a **concrete model or constructed input**. A study
explains its fields, actions and selection conditions, the conclusions obtained
from them, and any unverified model premises. It may concern a literature model
or an algebraic example constructed in this project for testing the interfaces.
A published source is not required for a model study.

The [literature coverage directory](../verification/README.md) organizes the
same work by **source location and formal comparison**: which equation, basis
candidate or claim was checked, under which conventions, and where the evidence
is recorded. Referring to papers alone does not determine document placement.

| Example | Reader-facing model study | Literature coverage entry |
| --- | --- | --- |
| [Conventional B-L input](minimal-bl/README.md) | Explain the declared fields, residual action and unresolved UV mass-radical input | Link the pinned source locations to the precise restricted certificates |
| [Constructed S3 input](s3-flavor-qque/README.md) | Explain the specified action, flavor-map gates and qque witness | Needed only if a particular external source is actually compared |
| [Li basis comparison](../verification/li-basis-coverage.md) | Needed only for a separate concrete model application | Index the source formulas and their coefficient-space comparison |

A result may appear in both views. Keep the model explanation here and the
source-to-result entry concise in the coverage ledger, with links between them.
The detailed theorem statement belongs in [current proofs](../proof/current/README.md);
plans, checkpoint evidence and integration records belong in [topics](../topics/README.md).
