# Minimal B-L: conditional SM coefficient checks

Fix conventional right-handed-neutrino charges -1, a singlet chi2 of B-L
charge 2, and a neutral SM Higgs. The source's discussion of this conventional
case is [1411.5042v2, introduction](https://arxiv.org/abs/1411.5042v2);
its alternative neutrino-charge and S3 constructions are not selected here.

Normalize X=3(B-L). The supplied SM-input dictionary after breaking is Z6
with physical quark charge 1 and lepton charge -3. On the fixed three-generation,
single-Higgs SM alphabet, Lean proves a derivative-free B1 minimum of dimension six, actual
uR²dR⁴ allowance and LLHH allowance. These are symmetry permissions, not
generated interactions. Before breaking, a Z5 subgroup excludes the selected
six-quark and LLHH contents at every Higgs count; subgroup B1 permission is
not asserted to be full U(1) permission.

The [action bridge](../../topics/conditional-model-input-check/bl-lr-results.md)
now proves an injective Z6-to-Circle map with image exactly the charge-six
nonzero-VEV stabilizer. It identifies the constructed continuous flavor actions,
including all signed SM gauge/Weyl fields and both neutral Higgs species, with
the cyclic input. The minimum-dimension consumer is also stated on this restriction.
Identification of these fields with a UV mass radical, the faithful global
quotient, neutrino external fields and UV matching remain external.
