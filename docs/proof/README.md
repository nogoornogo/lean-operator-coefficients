# Current Proof Library

The [current program](current/README.md) groups its proof directories in one
place. Proofs are organized by role in the graded algebraic completeness claim,
not by age or the order of discovery.

| Role | Contents |
| --- | --- |
| [Core](current/core/README.md) | General completeness, relation quotients, naturality and restriction |
| [Inputs](current/inputs/README.md) | Actions, field identifications, optional residual-group and multiplicity construction |
| [Applications](current/applications/README.md) | Bounded sectors, comparisons and literature certificates |

Math, Physics and GUT remain subject labels within each role. The
[result guide](current/RESULTS_AND_SCOPE.md) provides the reader-facing entry
points. Optional input routes are not universal premises. See
[assumptions](ASSUMPTIONS.md) and [interfaces](INTERFACES.md).
