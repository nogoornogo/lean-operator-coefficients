# Composable Prohibition Specifications

A stable content detector and target predicate select the coefficients to test
without changing an admitted field/action dictionary. The specification algebra
supports union, intersection, complement and arbitrary indexed union.
Prohibition and symmetry extension on a union are equivalent to the respective
properties on each constituent, degreewise and over all degrees. Intersection
has only the expected one-way inheritance, not the same iff.

Linear selectors form a separate interface on a common coefficient domain.
Their product vanishes iff every component vanishes, and this property transfers
through a supplied completeness equivalence. Restriction compatibility needs
an explicit commuting square. No physical flavor basis is automatically supplied.

The SM regression reuses actual signed fermion/Higgs actions and the integer
3B/L dictionary. Changing the target from absolute Delta B=1 or 2 to absolute
Delta B=1 or absolute Delta L=2 changes only a predicate. Actual character
actions and detection remain proof premises of prohibition. The dedicated
dipole regression combines arbitrary prescribed flavor pairs and proves
vanishing from distinct-weight detection on each pair.
