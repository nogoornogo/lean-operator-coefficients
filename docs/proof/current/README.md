# Current Completeness Program

Start with [current results and scope](RESULTS_AND_SCOPE.md) for the latest
fixed-input support/minimum results and their limits, and the
[application guide](APPLICATION_GUIDE.md) for model-input proof obligations.
Minimum-dimension claims concern derivative-free coefficients in their declared
field/action domain; they are not full-EFT or rate claims.

The current proof program is grouped by role:

- [Core](core/README.md): all-degree coefficient-space decomposition, naturality and restriction.
- [Inputs](inputs/README.md): supplied data and optional constructions.
- [Applications](applications/README.md): bounded sectors and verification.
- [Result guides](RESULTS_AND_SCOPE.md): the five reader-facing result categories.

See the [proof library](../README.md) for conventions, assumptions and the
retained concrete input/application dossiers. Optional input constructions are not universal
premises of the core theorem.

[Retained scoped dossiers](RETAINED_RESULTS.md) locate the role-based documents
previously kept in the history library. Placement does not broaden their claims.
