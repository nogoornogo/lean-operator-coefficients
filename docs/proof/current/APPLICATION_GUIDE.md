# Concrete model inputs and application guide

Start with the [current-result map](RESULTS_AND_SCOPE.md). The general
all-degree decomposition is the common foundation; a selected-sector example
does not replace its input or establish a full EFT classification.

## Representative inputs

The [S3 flavor sample](../../model-studies/s3-flavor-qque/README.md) supplies
noncommuting flavor actions, bijective invariant flavor maps and an actual
nonzero qque coefficient. The flavor-map gates do not establish physical
Yukawa masses or UV realization.

The [ten-candidate review](applications/GUT/CONDITIONAL_MODEL_INPUT_CHECKS.md)
compares named model dictionaries using their actual field/action restrictions.
DFPW and specified lepton-parity inputs give derivative-free B1 prohibition;
B3/P6 retain charged-Higgs component conventions. B-L has a certified VEV
stabilizer and SM action restriction, with the full UV mass radical external.
LR Higgs-kernel identification remains conditional on a source quadratic form
and selection premise. Ma tests retain SM external fields and exclude N/eta;
they do not derive the radiative mechanism.

A detecting subgroup can certify full-group prohibition on a matching domain;
subgroup permission does not supply a full-group witness. Each result has its
own sector and assumptions. See [model studies](../../model-studies/README.md)
for model-centered explanations and [coverage](../../verification/README.md)
for source-location comparisons. The SU6 search is stopped at its documented
boundary, with no protecting model or SU6-wide impossibility theorem claimed.

## Application procedure

1. **Freeze the coefficient domain.** State fields and conjugates, generation
   carriers, local gauge/Lorentz actions, residual group, scalar action, and
   derivative-free support predicate. Specify 6Y, 3B and physical-right versus
   all-left conventions. LFV needs its own transition selector.
2. **Check model-to-input correspondence.** Supply equivariant field maps and
   the relevant mass/kernel or scalar-selection conditions. A branching table,
   neutral charge or injective map alone does not identify a complete light
   kernel. Separate proved identities from supplied premises.
3. **Choose a theorem whose hypotheses match.** Fixed scalar cyclic q/l and a
   neutral Higgs can use structural support and finite charge criteria. Charged
   Higgs requires an action-aware mixed-field route. Nonabelian flavor can use
   actual statistics-constrained tensor Hom criteria. Prescribed dipoles have
   their own admissible coefficient-map interface.
4. **Separate prohibition, permission and minimum.** Prohibition must cover all
   selected contents; permission requires an actual nonzero witness. Exact
   derivative-free minimum requires attainment and a universal lower bound on
   the same domain. A supplied physical coefficient map is needed to discuss
   generation; allowance alone does not establish it.
5. **Check the direction of symmetry restriction.** Full-group invariance
   implies subgroup invariance. Subgroup prohibition therefore excludes the
   full-group sector, when restriction is certified. Subgroup permission need
   not give a full-group witness. The fields and selected domain must match.
6. **Record the outcome and evidence.** Use model-studies for the readable
   application, proof/current for theorem statements and topics for plans and
   verification. A missing source premise is an unresolved application, not
   an exclusion. A proved conflicting input condition is a bounded negative
   result. Code changes require builds/audits; editorial edits do not create
   a new proof baseline.
