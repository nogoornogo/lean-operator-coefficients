## Arbitrary-Multiplicity Six-Quark Inverse

The basis-free `SixQuarkFlavorCoordinates.assemble` extends the existing 25 local
reconstructions using finite-slot tensor separation and universal tensor lifting,
without finite-dimensionality of any flavor carrier. Its pure-tensor formula,
invariance and both coordinate inverse laws are proved. Consequently
`SixQuarkTypedFlavor.homLinearEquiv` and
`DeltaBTwoFlavorBridge.sectorHomEquiv` now require arbitrary complex up/down
modules and an arbitrary abstract residual group, not finite-dimensional ones.
The typed exchange equations and actual-field input identifications are unchanged.
This does not make the flavored coefficient space two-dimensional or establish
printed ten-seed completeness at arbitrary multiplicity.

The [regression topic](../../../../../topics/graded-sector-regressions/README.md) records
the 3,287-job prerequisite rebuild and eight strict transitive checks in
`AuditSixQuarkArbitraryFlavor`; the connection audits add 33 checks.
Historical finite-dimensional applications remain valid
specializations; their stronger assumptions should not be read as current
requirements of these inverse declarations.
