# Historical Physics Assumptions

These independently scoped results are not premises of the current general
completeness theorem. Archiving changes neither their statements nor their
recorded verification. Retain external premises and application limits.

### Retained Ledger Context

Updated: stage 01.

## Generated Matching Certificate

The [mediator/full-light certificate](../../../../../topics/mediator-full-light-certificate/README.md)
uses the canonical Q/up/e species of a supplied SM x H representation, an
invertible mediator mass, currents with proved joint exchange invariance,
and a nonzero alternating slot evaluation. A restriction constructor accepts
derived field maps and coefficient restrictions. Nonzero exterior descent is
derived from that evaluation, not assumed as a sector-level premise. The
residual-Hom conclusion uses the existing finite-dimensional and semisimple
SM completeness hypotheses. It does not prove that a supplied tau is a
particular model's actual radical, nor construct its currents; the SU(5)
application discharges these obligations using its existing source proofs.

## Conditions No Longer Required

These statements concern the interfaces named, not all historical wrappers.

| Stronger condition | Current replacement or boundary |
| --- | --- |
| Three actual conjugations | Two in the structural Abelian and non-Abelian endpoints; older certificates still convert |
| Full ambient unitarity | T x H unitarity for Abelian profiles; T-only unitarity for finite and compact-continuous coefficients |
| Finite H for qque internal coefficients | Compact H with continuous residual source and Q-target actions; H-unitarity is not assumed. [Compact theorem](../../../applications/Physics/COMPACT_LIGHT_QQUE.md) |
| One charge per species; exactly three generations | Natural charge profiles or actual H targets; positive/nonzero targets as above |
| Equal totals for all species | Independent Q/down positivity for the pair; Q alone for the qque endpoints |
| Global SM-plus-singlet character equality | Exact local dual matching at fifteen weights in the structural criterion |
| Fifteen monitored weights for qque alone | Matching at 0, 3, 8, 14 for both Abelian and non-Abelian local targets; actual four-slot support/coefficient retained. [Four-weight theorem](../../../applications/Physics/FOUR_WEIGHT_QQUE.md) |
| Supplied actual SM field decomposition for an exterior coefficient | Route B derives participating fields from a continuous compatible SM action and three species indices. This is an alternative input package, not an unconditional weakening of route A |
| Complete light spectrum equal to the SM | Core routes fix only the specified index; vectorlike or self-dual additions can cancel in it. The optional exact-spectrum entry deliberately reinstates a full-spectrum condition to derive the indices |
| The common residual index is the character of an actual representation | The signed virtual-index entry permits negative coefficients with positive total dimension, given a normalized finite irreducible presentation and matching character equations |
| The user supplies a normalized family and species matching proofs | The automatic species entry constructs both from actual continuous multiplicity representations; pairwise positive support of the resulting indices remains required |
| Whole Q/up/e virtual characters agree and Q total dimension is positive | The direct species entry needs only a common strictly positive constituent coefficient, plus the three actual species-index equations and compatible continuous SM action; the old package implies this new condition |
| A constituent is shared by all of Q/up/e | The pairwise entry needs positive support shared by Q/up and Q/e separately, with the same normalized species equations and compatible continuous action; nonzero symmetrization is derived |
| Dirac-only masses | General invariant complex-symmetric bilinear masses; the signed Dirac index remains a different convention |
| Scalar-linear Yukawa source | Separate [continuous scalar-dependent source wrappers](../../../applications/GUT/SCALAR_DEPENDENT_MODEL.md); finite higher-degree and mixed/conjugate-slot sources are constructed |

Outside the monitored weights (fifteen for the pair, four for qque), the
**local weight-target package** imposes no matching equation. Route B separately
constrains full-SM multiplicity indices. At monitored weights
it includes the opposite-weight dual contribution; vanishing
only at positive weights is insufficient. Arbitrary extra chiral matter is
therefore not licensed to change the prescribed index. Actual representation
and conjugation constraints still hold globally. No new phenomenologically
viable models or strictly larger embedding class are exhibited by the weakening.
