# Scalar Input Necessary Parameter Condition

The [consumer](../../../../../../Physics/FieldTheory/Jets/Scalar/Inputs/ScalarProhibitionConditions.lean)
reuses the full neutral complex scalar jet input, actual SL(2,C) Lorentz
action, signature (+---), four ordinary derivatives and arbitrary complex
coupling lambda. The complete differential ideal of box phi + lambda phi
cubed and the actual divergence range are imposed, without truncating
equation descendants or assuming an on-shell degree decomposition.

Box phi is proved to lie in the IBP relations. Thus every admissible global
coefficient f satisfies lambda times f(phi cubed) = 0. A nonzero cubic
evaluation requires lambda zero; a nonzero lambda forces that evaluation
to vanish. The selected wave/cubic coefficients satisfy the same vanishing
consequence directly, without an extension premise.

Existence at lambda zero, vanishing of all coefficients, arbitrary local
gauge/mixed-spinor extensions, analytic action integrals and physical rates
are not asserted. General target criteria retain their explicit extension,
support and action hypotheses; see the
[dossier](../../Math/DERIVATIVE_PROHIBITION_INPUT.md) and
[topic verification](../../../../../topics/derivative-prohibition-input/verification.md).
