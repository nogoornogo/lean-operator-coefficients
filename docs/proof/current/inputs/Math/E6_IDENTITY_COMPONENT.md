## 4. Proof structure

### Connected Candidate

Let `N = compactNormalizer` from [E6-0g](E6_COMPACT_NORMALIZER.md), and
let `k = compactMatrixLieAlgebra` be the actual real matrix Lie algebra.
[CompactIdentityComponent](../../../../../Math/LieGroups/E6/Minuscule/CompactIdentityComponent.lean)
defines `N0 = compactIdentityComponent` as mathlib's
`Subgroup.connectedComponentOfOne N`, not an assumed connected subgroup.

The subgroup is closed in N, compact, and connected. Its matrix image is
`compactIdentityMatrices`. The checked theorem is

```text
X in k  <->  for every real t, exp(t X) is in the matrix image of N0.
```

[MatrixLieGroupComponent](../../../../../Math/LieGroups/Matrix/MatrixLieGroupComponent.lean)
proves the reusable step: bundle any all-time exponential line in the
normalizer, prove it continuous with value 1 at zero, and map the connected
space of real parameters into the identity component. The converse uses
subgroup containment. Specialization to the original real form and all
eighteen compact generators is checked.

The dimension 78 belongs to k. A 78-dimensional **manifold** structure on
N0 is not yet constructed. Connectedness alone does not establish path
connectedness, exponential generation, simple connectedness, or the intended
global form; E6-0i supplies a separate proof of exponential generation.

### Full-Normalizer Center Control

[MatrixLieGroupScalar](../../../../../Math/LieGroups/Matrix/MatrixLieGroupScalar.lean)
proves that every unit-modulus scalar z satisfying `z^(card n) = 1`
defines a scalar special-unitary matrix that normalizes every real matrix
Lie subalgebra and is central in its full SU(n) normalizer.

[NormalizerCenter](../../../../../Math/LieGroups/E6/Minuscule/NormalizerCenter.lean) uses
mathlib's complex primitive-root theorem to construct

```text
z = exp(2 pi i / 27),   g = z I in N,
g in center(N),   g^m = 1 <-> 27 divides m,   orderOf(g) = 27.
```

In particular `g^3 != 1`. Thus N cannot be isomorphic to **any group whose
central elements all cube to 1**, as the abstract conditional nonisomorphism
theorem `compactNormalizer_not_equiv_of_center_exponent_three` proves.
This directly rules out giving the full normalizer the intended
order-three-center property. No named compact E6 carrier is assumed in
this argument, and it does not determine all of `center(N)`.

**This does not prove that g is outside N0, that N is disconnected, or that
the center of N0 has order three.** Those are separate global obligations.
The control does not refute the connected-candidate route or any existing
physical selection-rule theorem.
