# Input-Side Prohibition Conditions

The additive [derivative extension](DERIVATIVE_PROHIBITION_INPUT.md) applies
the scalar and common-constituent tests to actual IBP/EOM quotients, retaining
the selected-coefficient extension boundary. This nonderivative API is unchanged.

The [API results](../../../../topics/prohibition-input-api/results.md) describe
`Math.ProhibitionInput` and `Math.ScalarProhibitionNecessity`.
The selected-domain predicate is the existing `Forbidden`, and its factorwise
criterion uses the established coefficient decomposition. Specifications combine
through finite or arbitrary indexed unions on the same admitted field input.

The common-constituent converse retains explicit source semisimplicity.
Scalar detection is necessary only for a nontrivial admitted carrier with a
proved scalar action; the generic neutral converse constructs a dual functional
without finite-dimensionality. Actual mixed-factor detection uses the quotient
carrier, including local and statistics relations. A neutral zero carrier is
an audited negative control.

Forbidden larger-group coefficients and an allowed smaller-group coefficient
obstruct surjectivity of the actual selected restriction map. This does not
assert protection of all smaller-group coefficients. Physical admission and
model classification remain separate obligations.

Sources: [ProhibitionInput](../../../../../Math/RepresentationTheory/Protection/ProhibitionInput.lean),
[scalar necessity](../../../../../Math/RepresentationTheory/Protection/ScalarProhibitionNecessity.lean).
Verification is recorded in the [topic](../../../../topics/prohibition-input-api/verification.md).

The [representative catalogue](../../../../topics/prohibition-patterns/catalogue.md)
organizes five generic routes, four target connections and three controls.
`ProhibitionPatterns.cyclic_forbidden_iff` gives a concrete ZMod condition
under actual scalar action and admitted nontriviality. The Physics interface
selects arbitrary B/L target subsets and combines them with prescribed dipole
selectors without identifying their coefficient domains.

The [mixed-request extension](../../../../topics/mixed-selection-patterns/results.md)
adds per-target nonzero requirements alongside prohibition. An allowed selector
range records existence of an actual nonzero selected output; each target's
coefficient domain fixes its degree and symmetry conventions explicitly.
