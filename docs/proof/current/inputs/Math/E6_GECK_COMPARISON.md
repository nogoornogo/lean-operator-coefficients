## 4. Proof structure

### Proof Route

1. [SerreMatrixBasis](../../../../../Math/LieAlgebras/SerreMatrixBasis.lean)
   constructs a `LieAlgebra.Basis` on the Lie algebra generated by actual
   integral raising/lowering matrices. Besides the Serre relations, it
   requires independent Cartan generators and a nondegenerate Cartan
   matrix; neither is silently inferred from the presentation.
2. [MatrixLieBasis](../../../../../Math/LieGroups/E6/Minuscule/MatrixLieBasis.lean) supplies
   those inputs for E6 and D5. Cartan independence follows from the
   [kernel-checked finite bases](E6_LIE_CERTIFICATE.md). Small integral
   checks identify the Cartan entries in those bases and verify the
   Cartan determinants. TauCeti supplies the E6 Serre relations; its
   injective-subdiagram theorem supplies the D5 relations.
3. [RootSpaceDimension](../../../../../Math/LieAlgebras/RootSpaceDimension.lean)
   exposes `dim L = dim H + number of roots` for a split finite-dimensional
   Killing Lie algebra. It reuses the pinned public TauCeti dimension theorem,
   converting `Finset.card` to the existing `Nat.card` interface.
4. [PinnedGeckBasis](../../../../../Math/LieAlgebras/PinnedGeckBasis.lean)
   numbers the scalar-extended Geck basis by the pinned Bourbaki nodes.
   Mathlib's root-system equivalence and simplicity theorem give simplicity
   and dimensions **78/45 of the actual carriers**, not just their ambient
   matrix coordinate counts.
5. [BasedLieComparison](../../../../../Math/LieAlgebras/BasedLieComparison.lean)
   compares the two bases via their diagonally generated product.
   The pinned mathlib `prodEquivLeft` already gives the source projection
   equivalence assuming only target simplicity and matching Cartan matrices.
   It is called directly; both projections are surjective. Equal dimensions make the
   second projection injective too. This constructs the equivalence and
   proves its generator equations.

Thus **equal dimensions alone are not the argument**. Matching bases,
the proper-product theorem, target simplicity, and surjectivity supply the
missing structure. Nor is injectivity of the general Serre-to-Geck map
assumed. No additional external numerical certificate was necessary.

## 6. Scope and limitations

### Library Boundary

The pins are unchanged. `BasedLieComparison` uses `import all` to access
the private product-construction helpers of the pinned mathlib
`Algebra/Lie/Basis/Prod.lean`. Their use is isolated behind public theorems
whose types do not expose those helpers; dependency upgrades will need a
targeted compatibility check. No package source was modified.

The earlier projection-proof adaptation was unnecessary: Lean omits the unused
source-simplicity section variable from the type of `prodEquivLeft`. The public
`equivOfReindex` does require both sides simple, but the internal helper does
not. A public equal-dimension/generator-preserving wrapper may still be useful
upstream; the projection argument itself is already upstream mathematics.
The root-space dimension formula is also already public in pinned TauCeti, so
it is no longer a missing-theorem contribution candidate.

See the [direct-reuse review](../../../../topics/mathlib-direct-reuse/README.md) for
implementation provenance. The formerly retained local license notice/text
were removed in [subsequent maintenance](../../../../architecture/DISTRIBUTION.md);
this does not select a repository-wide license or change historical versions.
