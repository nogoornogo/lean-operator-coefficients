# GUT Applications

This layer assembles common selection-rule/chirality consumers and the SU5,
SU6, SUN, Sp, Spin10 and E6 applications. Shared mathematics lives in
[Math](../Math/README.md); shared field theory and SM interfaces live in
[Physics](../Physics/README.md). Model-specific adapters stay here.

See the [module layout](../docs/architecture/MODULE_LAYOUT.md) and
[proof dependency map](../docs/topics/proof-program-context/proof-dependencies.md).

The intended universal no-go theorem must not be claimed merely from the
conditional assembly interfaces.
